How it works

Reverse-engineer the tags that already rank

Reelcraft looks at your title the same way YouTube's search does, then cross-references the tag sets of the videos already winning that query — so you're not guessing at metadata, you're copying a proven pattern.

1. Match the query

Your title is matched against live YouTube search results to find the videos currently ranking for the same intent.

2. Pull real tags

Public tag data is extracted from your video and each close competitor — no estimation, no keyword guessing.

3. Copy & publish

Grab the primary set or every related tag in one click and drop it straight into YouTube Studio.
