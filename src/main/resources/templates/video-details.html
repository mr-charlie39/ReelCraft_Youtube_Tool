How it works

Every public data point, in one lookup

Instead of hopping between YouTube Studio tabs, Reelcraft resolves a single video ID into its thumbnail, full description, channel, publish date and tag list — all pulled straight from YouTube's own metadata, side by side.

1. Resolve the ID

A pasted URL or bare ID is normalized so any YouTube link format works the same way.

2. Pull the metadata

Title, channel, publish date, full description and tag list are gathered in a single pass.

3. Compare at a glance

Everything sits in one panel, side-by-side with the thumbnail — no digging through separate pages.
